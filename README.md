\# AI DevOps Release Dashboard



A simple Flask based release dashboard built to demonstrate core DevOps practices including automated testing, Docker containerization, health checks, Git, and GitHub based CI/CD.



\## Project Overview



The application shows a simple release dashboard with:



\- Application version information

\- Environment information

\- Health status

\- `/health` endpoint for monitoring



\## Technology Stack



\- Python

\- Flask

\- Pytest

\- Docker

\- Git

\- GitHub

\- GitHub Actions
